# Campus-Delivery-System-Java
# java-校园跑腿系统源码（管理端+用户手机端）
本项目为「校园跑腿平台」，是一个面向校园场景的跑腿服务多端项目，包含管理端与用户端两个端。管理端基于 Spring Boot 提供后台管理服务，用户端基于 uni-app Vue3 提供移动端应用。项目围绕跑腿任务的全生命周期展开，涵盖任务发布、任务审核、跑腿员 入驻、订单流转、公告管理、数据统计等核心业务！
### 1、系统功能
⭕ 管理后台

· 登录

· 首页

· 跑腿任务管理：任务列表 | 任务审核 | 任务分类

· 跑腿员管理：跑腿员列表 | 入驻审核

· 订单管理：订单列表

· 用户管理：用户列表

· 公告管理：公告列表

· 数据统计：任务统计 | 订单统计

· 系统管理：账号管理 | 角色管理 | 菜单管理

⭕ 用户端前台（手机端）

登录/注册 | 首页 | 任务大厅 | 发布任务 | 任务详情 | 我的任务 | 我的订单 | 订单详情 | 跑腿员入驻 | 平台公告 | 我的

### 2、技术栈与工具
本项目采用稳定且广泛应用的技术栈，结合 Java 后端开发与 uni-app 移动端开发，确保开发流程清晰、系统稳定。

技术选型

· 后端：Java 21 + Spring Boot 2.7

· 数据库：MySQL 8.0

· 构建工具：Maven 3.9

· 用户端：uni-app Vue3

· 开发工具：VSCode / IntelliJ IDEA / HBuilderX
